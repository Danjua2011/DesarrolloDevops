# 🎬 CineReview

CineReview es una plataforma web para consultar películas,
ver calificaciones y compartir reseñas con otros usuarios.

## 🚀 Funcionalidades

- Visualización de películas
- Buscador de películas
- Calificación mediante estrellas
- Reseñas de usuarios
- Diseño responsive
- Interfaz moderna

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
